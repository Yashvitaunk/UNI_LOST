This is the frontend of the Lost & Found Portal, a web application that helps users report, find, and claim lost items in an organized way.

🌐 Built With

HTML5, CSS3, and JavaScript

Clean, responsive UI with intuitive forms and layouts

AJAX/Fetch API for seamless communication with the backend

✨ Features

📝 Report Lost or Found Items using a simple form

🔍 Search Filters to find items by category, location, or type

📄 Dynamic Item Listings – Displays available lost/found items from the backend

✅ Claim Request Submission via a form connected to the backend API

📬 Email Confirmation Pages (optional HTML templates if backend uses email)

🔗 Integration

Connects to a backend powered by Node.js, Express, and MongoDB

Uses Fetch API to make calls to backend endpoints (e.g., /api/items, /api/claims)

Handles form submissions and renders results based on backend responses

📁 Folder Structure

index.html – Login page

dashboard.html – Main page after login

lost_item_found2.html – Form to report lost/found item

notification2.html – Displays confirmations or alerts

search_matching_results.html – Shows filtered item results
